羊毛织物的分类
多重维度 · 精纺与粗纺 · 护理

「羊毛面料」不是一类，而是一族。同一批羊毛，精梳还是粗梳，出来的是完全两种性格的布； 而在精纺与粗纺之外，还有纤维来源、细度、品质支数与后整理四条并行的分法。 本讲把这五条线索一次理清，并落到最基本的一件事上——它该怎么洗。

01学习目标

「这是羊毛面料」只是第一句话。真正要能回答的是：哪一种羊毛、用什么纺法、什么整理、该怎么洗。

知识目标

  • 说出羊毛分类的五条并行维度
  • 说明精梳毛纺与粗梳毛纺在原料、流程、纱线结构上的根本差别
  • 复述品质支数的定义，并说明支数与纤维细度的关系
  • 解释羊毛为什么能够缩绒，以及为什么缩绒不可逆

能力目标

  • 由织物的外观、手感与克重，判断它属于精纺还是粗纺
  • 见到「64 支全毛哔叽」这类规格串，能读懂其含义
  • 针对一块羊毛面料，给出可执行的洗涤与保养建议
  • 举例说明同一种面料名（如法兰绒、啥味呢）为何会横跨精粗两系

素养目标

  • 认识到「分类不分对错，只看按哪把尺子」——口径先行
  • 理解护理不当造成的毡缩是不可逆损伤，属使用责任
  • 养成看洗标、看成分、看支数的消费习惯

本讲的知识链条

五条维度

02分类的多重维度

羊毛织物不是按一把尺子分的。把尺子认清楚，比背品种名有用得多。

只讲「精纺 / 粗纺」，其实只占了一条线索。完整的分类至少还有四条并行的维度， 它们各自回答一个不同的问题：

维度一：按纤维来源

「羊毛」严格说指绵羊毛。除此之外，来自其他动物的毛纤维统称特种动物毛，各有鲜明性格：

阅读面料成分时要注意：「羊毛」与「羊绒」只差一个字，价格差好几倍，且纤维完全不同—— 前者来自绵羊，后者来自绒山羊。国家标准要求纤维名称规范标注，成分标签是判断的第一依据。

毛纺行业习惯把绵羊毛按平均直径与长度分成四档，这直接决定了它适合做什么：

维度三：按品质支数

品质支数（又称布拉福德支数，Bradford count）是毛纺行业沿用至今的一套间接指标， 它不是直接量纤维，而是用「能纺多细的纱」来反推纤维的粗细：

维度四：按纺纱系统 —— 精纺与粗纺

这是影响成品性格最大的一条线索，也是本讲第 3 节的主题。 一句话概括：精梳去掉短纤维、把长纤维梳直；粗梳保留长短纤维、让它们交错蓬松。

维度五：按后整理

1缩绒整理
利用羊毛的缩绒性使呢面紧密、绒面丰润。麦尔登、海军呢的关键工序。
2起绒 / 拉毛
机械拉出纤维端头形成绒毛。法兰绒、大衣呢的标志性整理。
3防缩（机可洗）
通过剥鳞片、树脂覆盖等方式抑制缩绒，使产品可机洗。注意：防缩处理会改变手感。
4压烫 / 电压
使呢面平整、光泽增强。精纺毛织物常用，用于获得「呢面洁净」的外观。
为什么必须先说清「哪把尺子」 你会在不同资料里看到互相矛盾的说法——「法兰绒是粗纺」与「法兰绒是精纺」都对， 因为精纺法兰绒与粗纺法兰绒（绒面法兰绒）是两类实际存在的产品； 「啥味呢」在中国精纺毛织品的标准品种序列中在列，而英文 Cheviot 在英文语境下又常指粗纺厚呢。 不是谁错了，是口径不同。回答问题时先说口径，再下结论。

同一批羊毛，精梳还是粗梳，出来的是两种性格完全不同的布。

现场判断三步法

第一步：看织纹

织纹清晰、能看到斜纹线或清晰的组织点 → 偏精纺； 表面有绒毛、纹理模糊、看不出组织 → 偏粗纺。

第二步：摸手感

滑爽、挺括、有身骨、回弹快 → 偏精纺； 丰满、蓬松、柔软、有暖感 → 偏粗纺。

第三步：看整理

呢面洁净、有压烫的光泽 → 偏精纺； 表面有缩绒或起毛形成的绒面 → 偏粗纺。

一句话记住分水岭 精梳拿走「短」，粗梳留下「乱」。 短纤维被拿走 → 纱线必须细而光洁；长短纤维混在一起 → 纱线必然蓬松而毛茸。 后续所有差别——外观、手感、耐用性、季节——都是这一步的连锁反应。

04鳞片层与缩绒性

羊毛能做成丰厚的呢面，靠的是它；羊毛衣物洗坏，也是栽在它手上。

羊毛纤维的三层结构

鳞片层（表皮层）

最外层，由角质化的扁平细胞像瓦片一样叠覆而成。 它的自由端统一指向毛梢（纤维的尖端方向），是羊毛缩绒性的结构根源。

皮质层

纤维的主体，由纺锤形细胞沿纤维轴向排列，决定羊毛的强度、伸长与弹性。 细羊毛的皮质层还分为正、偏皮质两侧，形成天然卷曲。

髓质层

位于中心的疏松多孔结构，含空气。细羊毛常无髓质层，粗羊毛多有， 髓质层会降低强度与弹性，但提高保暖性。

图 4-1　鳞片层的方向性与定向摩擦效应。两个方向的摩擦系数不同， 使纤维在反复的机械作用下只能单向地向毛根方向蠕动，彼此穿插缠结—— 这就是缩绒（毡化）的机理。

定向摩擦效应：缩绒的机理

羊毛鳞片层方向一致，使纤维在两个方向上的摩擦系数不相等，这一现象称为 定向摩擦效应（也称差微摩擦效应）。它带来一个关键后果：

从摩擦差异到缩绒 在湿热（水、热、蒸汽）与机械外力（搓揉、搅动、冲击）共同作用下， 纤维不断被推挤，却只能单向蠕动、无法回退； 于是纤维相互穿插、缠结、纠缠成团，纤维端头互相锁住，织物收缩、增厚、变硬。 这一过程称为缩绒；当缠结致密到纤维无法再移动时，就形成毡化。

术语提示：不同教材对「顺鳞片／逆鳞片」的命名取向略有差异。 判断时以结果为准——摩擦系数小者容易滑动，大者滑动受阻，不必纠结于名称。

缩绒的两面性

被利用的一面：整理工艺

  • 缩绒整理使呢面紧密、绒面丰润、手感丰厚——麦尔登、海军呢、大衣呢的关键工序；
  • 毛衫洗后因轻微缩绒而更丰满，这是可接受的变化；
  • 缩绒还能提高织物的紧度与保暖性、掩盖织纹。

被利用的另一面：使用事故

  • 热水 + 搓揉 + 碱性洗涤剂 → 严重毡缩：衣服缩小一两号、变硬板结；
  • 毡化不可逆——纤维已互相锁死，无法通过任何洗护手段恢复；
  • 烘干、滚筒搅拌同样会加剧缩绒，是常见的第二重损伤。

为什么防缩处理能机洗

既然缩绒源于鳞片层，防缩的思路就是「拆掉或盖住它」：

剥鳞片法

用氧化剂或酶处理，部分剥除或钝化鳞片边缘，使两个方向的摩擦差异大幅减小。

树脂覆盖法

用聚合物在纤维表面形成薄膜，把鳞片「抹平」并使其牢固，从而抑制单向蠕动。

混纺与设备

混入不缩绒纤维降低整体缩绒倾向；或采用专门的羊毛程序（低温柔和、低水位、弱机械）。

一个常被忽略的代价 防缩处理会改变手感——剥鳞片法容易造成纤维损伤与手感偏硬， 树脂覆盖则可能影响吸湿透气与光泽。因此「可机洗」并不等同于「更好」： 高档精纺面料往往保留天然鳞片、不防缩，以换取更好的手感与光泽，代价是必须干洗或极轻柔手洗。

06洗涤与保养

这一节是前面所有机理的落点：知道它为什么会坏，才知道该怎么洗。

先看两条铁律

① 高温 + 机械 + 碱性 = 毡缩

这三者凑齐，缩绒几乎必然发生，而且不可逆。 因此羊毛洗涤的核心不是「洗干净」，而是避免这三者同时出现： 用低温（30 ℃ 以下）、少搅动（不搓揉、不拧绞）、中性洗涤剂。

② 洗标优先于一切经验

护理符号依 GB/T 8685—2008 的规定标注，是产品生产方对该件衣物的正式承诺。 特别是防缩处理（机可洗）产品，其可承受的洗涤强度与普通羊毛完全不同—— 先看洗标，再决定怎么洗。

特种动物毛的额外注意

山羊绒

纤维极细、强度较低，最忌搓揉与拧绞；建议干洗或专用羊绒洗涤剂冷水手洗， 平铺阴干，绝不可机洗甩干。

马海毛

鳞片不明显、不易毡缩，但纤维刚挺，受压易失去蓬松感； 洗涤后宜轻抖整形，避免重压。

羊驼毛 / 兔毛

羊驼毛强度较好但仍宜干洗；兔毛纤维抱合力差、易掉毛， 应用冷水极轻手洗或干洗，避免摩擦。

四个最常见的护理错误

1热水泡洗
以为热水能去污，结果触发缩绒。羊毛只认冷水或 30 ℃ 以下温水。
2搓揉与拧绞
机械外力是缩绒的另一个必要条件。应改为按压。
3洗衣机常规程序与烘干
除非洗标明确标注机可洗，否则普通程序与烘干都会造成开裂与毡缩。
4悬挂晾干
湿态羊毛自重会使衣物拉长变形，且难以恢复。必须平铺。
如果已经洗坏了 若发生毡缩、尺寸明显变小且手感变硬板结，属不可逆损伤—— 纤维已互相锁死，任何柔顺剂、蒸汽或拉伸都无法复原。 可尝试的补救仅限于「整形到略大尺寸后平铺定型」，用于轻微变形； 严重毡缩只能改作其他用途。预防的成本远低于补救。

07自测练习

先自己回答，再点开对照。答不上来的，回到对应那一节。

1精纺与粗纺最根本的差别是什么？由哪一步工艺造成？

最根本的差别在于原料中是否保留短纤维，由是否经过精梳工序造成。

精纺（精梳毛纺）：经精梳机剔除短纤维与杂质，留下的长纤维被反复针梳拉直、 平行顺直，因此毛纱中纤维排列整齐、结构紧密、外观光洁，可纺得较细的纱。

粗纺（粗梳毛纺）：不经精梳，长短纤维全部保留，只能靠梳毛机开松分条， 因此纤维排列紊乱、呈自然弯曲相互捻合，毛纱蓬松、表面多茸毛，纱较粗。

后面所有差别——外观、手感、耐用性、适用季节、克重——都是这一步的直接后果。

2「64 支全毛哔叽」里的「64 支」是什么意思？它反映的是纤维的什么性质？

「64 支」指羊毛的品质支数（布拉福德支数）为 64s。

定义：一磅（约 0.454 kg）洗净并梳理顺直的毛条，能纺出多少个 560 码（约 512 m）长的毛纱绞， 就是多少支。能纺出 64 绞即 64 支。

它间接反映的是纤维的平均直径：64 支对应的平均直径约为 21 μm 左右 （USDA 标准给出的区间为 20.6～22.0 μm）。支数越高，纤维越细。

「全毛」表示经纬全部为羊毛（含与其他动物毛混纺或纯纺的情况按标准口径处理）， 与支数一起构成规格串「原料 + 支数 + 品名」。

3为什么羊毛衫用热水加碱性洗衣粉搓洗后会缩小、变硬？请按机理顺序说明。
  1. 结构前提：羊毛纤维外层是鳞片层，鳞片的自由端统一指向毛梢。
  2. 定向摩擦效应：纤维向毛根方向滑动时鳞片顺伏、摩擦系数小； 向毛梢方向滑动时鳞片张开互卡、摩擦系数大。两个方向不相等。
  3. 触发条件：热水使纤维吸湿膨润、变得柔软易变形；碱性洗涤剂进一步加剧膨润并损伤纤维； 搓揉提供了持续的机械外力。
  4. 结果：纤维被反复推挤，却只能单向蠕动、无法回退，于是相互穿插缠结、 端头互相锁住，织物收缩增厚、手感板结。
  5. 不可逆：纤维已互相锁死，属于毡化， 任何柔顺剂或拉伸都无法恢复原状。

要点：湿热 + 机械外力 + 碱性，三者同时出现才会严重毡缩。 洗羊毛的正确做法就是拆掉其中至少两个条件。

4麦尔登与凡立丁各属于精纺还是粗纺？分别写出两条判断依据。

麦尔登 → 粗纺。

  • 外观：经缩绒整理，绒毛密实、看不见织纹；
  • 手感：厚实、硬挺、温暖，克重大（常见 400 g/m² 以上）。

凡立丁 → 精纺。

  • 外观：平纹、结构疏松、呢面光洁，织纹清晰可辨；
  • 手感：轻薄、光滑、透气，克重小（常见 150～220 g/m²）。

对比要点：一个是「绒面看不出纹」，一个是「光面看得清纹」。

5为什么「法兰绒」既可以算精纺、也可以算粗纺？遇到这种说法该怎么处理？

因为现实中确实存在两类法兰绒：

  • 精纺法兰绒（worsted flannel）：以精梳毛纱织制，表面有轻微绒面、织纹仍可辨认， 手感细洁而有身骨，多用于西装、西裤；
  • 粗纺法兰绒（绒面法兰绒）（woolen flannel）：以粗梳毛纱织制并经拉绒整理， 绒毛丰富、织纹模糊，手感柔软蓬松，多用于衬衫、家居服。

处理办法：不要争论「到底属于哪一系」，而是先明确口径—— 是指哪一类产品、依据什么标准或习惯分类。分类没有绝对对错，只有口径是否说清。

6「啥味呢」应归入哪一系？它在中文里是什么性质的名称？

按中国毛纺行业的品种序列，「啥味呢」属于精纺毛织品的正式品种名之一 （精纺毛织品常见品种包括哔叽、华达呢、凡立丁、派力司、啥味呢、花呢、女衣呢等）。

「啥味呢」是中文行业惯用的品种名，而不是英文译名。 其英文对应词为 Cheviot，而 Cheviot 在英文语境中既可指粗纺缩绒厚呢， 也可指精纺基础上的缩绒产品（worsted cheviot，可译作「精纺缩绒粗呢」）。

因此处理办法是：中文品名照用「啥味呢」，同时把「精纺缩绒粗呢」单列， 说明两者所指与英文对应关系，而不是简单地把它改归粗纺。遇到译名与归属存疑的品种， 宜标注清楚所指口径，避免一刀切。

7一件山羊绒衫洗后缩小、变硬了，还能恢复吗？为什么？

不能恢复。这属于不可逆的毡化损伤。

原因与羊毛相同：鳞片层带来的定向摩擦效应，使纤维在湿热与机械作用下单向蠕动、 相互缠结并锁死。缠结一旦致密，纤维之间的相对位置就被固定，无法再解开。

山羊绒纤维更细、更柔软，缩绒倾向明显，因此损伤往往比普通羊毛更快、更严重。 唯一的办法是预防：冷水、中性洗涤剂、按压式洗涤、平铺阴干。

8请为一件粗纺粗花呢大衣给出一条可执行的洗涤建议，并说明理由。

建议：优先送干洗。

理由有三条：

  1. 粗花呢以粗梳毛纱织制，表面绒毛多、结构相对疏松， 纤维的可移动性大，一旦遇湿热与机械作用很容易进一步毡缩；
  2. 粗纺产品多已经过缩绒或起绒整理，尺寸与绒面已「定型」， 再经水洗易发生尺寸变化与绒面倒伏；
  3. 大衣体积大、克重大，家庭水洗时的自重与搅动都难以控制， 湿态悬挂还会把衣身拉长变形。

若仅局部沾污，可先用微湿的白布轻按吸除，避免大面积浸水； 送洗前务必把洗标上的护理符号看清楚（依 GB/T 8685—2008）。

08一页速记

五条维度、一个分水岭、一条机理、一套护理。

五条并行维度

  1. 纤维来源：绵羊毛 / 山羊绒 / 马海毛 / 羊驼毛 / 骆驼毛 / 兔毛 / 骆马毛
  2. 细度与长度：细毛 / 半细毛 / 长毛 / 粗毛
  3. 品质支数：28s ～ 70s，支数越大纤维越细
  4. 纺纱系统：精纺 / 粗纺 ← 影响最大的一条
  5. 后整理：缩绒 / 起绒拉毛 / 防缩 / 压烫

方向相反：支数 ↑ → 直径 ↓。

缩绒：三要素与结果

  • 结构前提：鳞片层自由端指向毛梢
  • 机理：定向摩擦效应 → 纤维单向向毛根蠕动 → 缠结锁死
  • 触发：湿热 + 机械外力 + 碱性
  • 结果：收缩、增厚、变硬；不可逆

护理四原则

  1. 先看洗标（GB/T 8685—2008 符号）
  2. 低温：≤ 30 ℃，冷热一致
  3. 中性洗涤剂：忌碱性、忌含酶
  4. 按压不搓揉、不拧绞；平铺阴干、忌悬挂暴晒
一句话串起本讲 鳞片决定了它为什么会缩；精梳还是粗梳决定了它成什么样；洗标决定了你该怎么对待它。 三者串起来，就是羊毛织物从纤维到衣橱的完整链条。
